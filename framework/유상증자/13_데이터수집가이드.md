# 유상증자 데이터 수집 가이드 — 어디서 무엇을 뽑을 것인가

케이스 작성 시 **이 순서대로** 원문을 훑으면 필요한 값이 다 나온다.
목표: 기억·기사 요약이 아니라 **원문 공시 기준**으로 케이스를 채우는 것.

---

## 1. DART (dart.fss.or.kr) — 읽을 문서와 순서

### ① 「주요사항보고서(유상증자결정)」 — 최초 공시, D-day
가장 먼저 나오는 문서. 여기서 뽑는 것:

- 신주의 종류와 수 → **신주수**
- 증자전 발행주식총수 → **희석률 계산의 분모**
- 1주당 예정 발행가액, 자금조달의 목적(시설자금 / 영업양수자금 / 운영자금 / 채무상환자금 / 타법인증권취득자금)
- **★ "자금조달의 목적" 표의 항목별 금액** — 이게 유형코드 분류의 원천 데이터
- 증자방식 (주주배정후실권주일반공모 / 제3자배정 / 일반공모)
- 신주배정기준일, 청약예정일, 납입일, **신주상장예정일** (= 오버행 해소 시점)

> `타법인증권취득자금` 항목이 잡혀 있으면 M&A(E 또는 F)가 섞인 것이다. 대상 법인을 반드시 확인.

### ② 「증권신고서(지분증권)」 — 실질 정보의 본체
- **제1부 모집·매출에 관한 사항 → "자금의 사용목적"**: 항목별 금액, **집행 예정 시기**, 우선순위
- **"투자위험요소"**: 회사가 스스로 밝힌 리스크. 특히 *사업위험*에 캐파·수요·고객 관련 서술
- **증설 관련 기재**: 신규 공장 캐파, 완공 예정일, 기대 매출 — 페이백 계산의 재료
- **최대주주 등의 청약 참여 계획** ← 시그널 변수 6번의 근거

### ③ 「[정정]증권신고서」 이력 ★ 반드시 확인
- 정정 횟수와 사유. **금감원 정정요구에 의한 정정**이면 거버넌스 적신호(스코어카드 9번).
- 정정 전후로 **자금 사용목적·조달금액이 바뀌었는지** 대조. 바뀌었다면 그것이 T1의 핵심 이벤트.

### ④ 「투자설명서」 / 「[발행조건확정]증권신고서」
- **1차 발행가액**, **최종(확정) 발행가액**, 최종 모집총액
- 예정가 → 1차 → 최종의 **궤적**을 반드시 기록한다. (상승 = 시장 승인, 하락 = 시장 거부)

### ⑤ 「증자등의 주요사항 보고서」 / 청약 결과 공시
- 구주주 청약률, **실권율**, 일반공모 경쟁률
- 최대주주 실제 참여 주식수

### ⑥ 이후 추적 공시 (T2 검증용)
- 「신규시설투자등」 — 실제 집행
- 분기·사업보고서의 **자금의 사용내역** 표 → 조달자금을 계획대로 썼는지
- 「단일판매·공급계약체결」 — 증설 캐파에 대한 실수요 확인

## 2. 시세·수급 데이터

- 공시일(D-day) 기준 종가, 그리고 **D+1 / D+5 / D+20 / D+60 / D+120 / D+250** 종가
- 같은 기간 **KOSPI(또는 KOSDAQ) 및 동종업종 지수** — 초과수익률을 봐야 이슈 효과가 분리된다
- 공시 전후 거래량 급증 배수
- 외국인·기관 순매수 추이 (T1에서 누가 받았는가)
- 발행주식총수 변화 (신주상장일 전후)

> **주의**: 공시가 장 마감 후에 나왔다면 D-day는 공시일, 첫 반영일은 **다음 거래일**이다.
> 케이스에는 `공시일`과 `첫 반영 거래일`을 따로 적는다.

## 3. 최소 수집 항목 체크리스트 (이 10개는 반드시)

- [ ] 1. 조달 총액
- [ ] 2. 신주수 / 증자전 발행주식총수 → **희석률**
- [ ] 3. 자금 사용목적 **항목별 금액과 비중**
- [ ] 4. 발행가 궤적 (예정가 → 1차 → 최종) 및 조달액 변동
- [ ] 5. 증자 방식 + 최대주주 참여율
- [ ] 6. 증설 캐파 규모와 **가동 예정 시점**
- [ ] 7. 직전 4개 분기 매출·영업이익·순이익
- [ ] 8. 부채비율·현금성자산 (차입 여력이 있었는데도 증자했는가)
- [ ] 9. 정정신고서 이력 / 감독당국 개입 여부
- [ ] 10. 신주상장예정일 (오버행 해소일)

---

## 4. 계산 공식 모음

```
희석률 d        = 신주수 ÷ (증자전 발행주식총수 + 신주수)
증자후 총주식수  = 증자전 + 신주수
필요 ROIC r*    = (직전4Q 순이익 ÷ 조달금액) × d ÷ (1 - d)
페이백(년)      = 조달금액 ÷ 증설 연간 영업이익 증분
초과수익률       = 종목 수익률 - 벤치마크 수익률   (동일 기간)
```
