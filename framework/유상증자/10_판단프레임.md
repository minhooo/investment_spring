# 유상증자 판단 프레임 — 왜 같은 유상증자가 호재와 악재로 갈리는가

---

## 1. 출발점: 유상증자는 "확정된 악재 + 불확실한 호재"의 묶음이다

주가 = EPS × PER 로 놓으면,

- 유상증자는 **분모(주식수)를 즉시, 확정적으로** 늘린다 → EPS 즉시 희석 → **확정 악재**
- 조달자금은 **미래에** 순이익 E를 늘릴 **수도** 있다 → **불확실한 호재**

시장은 확정된 것을 먼저, 크게 반영한다. 그래서 **거의 모든 유상증자는 발표 직후 하락한다.**
발표 직후 하락 여부로는 좋은 증자와 나쁜 증자를 구분할 수 없다. **구분은 그 다음에 일어난다.**

> 핵심 명제: **악재 유상증자와 호재 유상증자는 T0에서 구분되지 않는다. T1과 T2에서 갈린다.**

---

## 2. 시간축 3단계 — 이 프레임의 뼈대

| 단계 | 시점 | 시장이 반영하는 것 | 관찰 포인트 |
|---|---|---|---|
| **T0 — 희석 충격** | D+0 ~ D+20 | 희석률, 오버행 공포, 배신감 | 하락폭 자체는 정보가 적다. **하락의 구성**(어느 항목 때문인지)을 분해할 것 |
| **T1 — 불확실성 해소** | D+20 ~ 신주 상장일 | 자금용도의 질, 발행가 확정, 청약률, 대주주 참여, 규제 개입, 계획 변경 | **여기서 좋은 증자와 나쁜 증자가 갈린다.** 발행가 궤적·조달액 변화가 시장의 평결 |
| **T2 — 실적 검증** | 증설 가동 후 2~6분기 | 캐파 → 매출 → 이익 전환 여부 | EPS가 희석을 추월하면 재평가. 못 하면 영구 할인 |

케이스를 쓸 때 주가 수익률을 **D+1 / D+5 / D+20 / D+60 / D+120 / D+250** 로 나눠 기록하는 이유가 이것이다.
T0의 낙폭이 아니라 **T0 낙폭 대비 T1 회복 속도**가 유형을 판별한다.

## 3. 정량 기준 — 희석 vs 이익증분의 경주

기호:
- `d` = 희석률 = 신주수 ÷ (기존 발행주식수 + 신주수)
- `C` = 조달금액
- `r` = 조달자금의 세후 투하자본이익률 (증설 프로젝트 ROIC)
- `NI` = 직전 4개 분기 지배주주 순이익

**EPS 중립 조건:**

```
C × r ÷ NI  ≥  d ÷ (1 - d)
```

즉 필요 수익률:

```
r*  =  (NI ÷ C) × d ÷ (1 - d)
```

`r > r*` 이면 유상증자는 EPS를 **높인다**. `r < r*` 이면 영구히 희석이다.

### 실무용 간이 판정 — 페이백 연수

정확한 ROIC를 알기 어려우니, 실무에서는 이걸 쓴다.

```
페이백 = 조달금액 ÷ (증설로 늘어날 연간 영업이익 증분)
```

| 페이백 | 판정 |
|---|---|
| ≤ 3년 | 강한 호재 후보. 희석을 이길 가능성 높음 |
| 3~5년 | 중립. 수요 가시성이 결정 |
| 5~8년 | 약세. 사이클이 버텨줘야 함 |
| > 8년 또는 산출 불가 | 사실상 자본 소각. 형태가 증설형이어도 결과는 채무상환형과 유사 |

증분 영업이익을 추정할 수 없다면 — **그것 자체가 답이다.** 회사가 캐파와 단가와 고객을 제시하지 못하는 증설은 C형이 아니다.

## 4. 5대 판별 변수

### 변수 1 — 자금 용도: 과거를 메우는가, 미래를 사는가

가장 큰 변수. 상세 분류는 `11_분류체계.md`.

한 줄 판별: **조달자금이 대차대조표의 부채를 줄이는가(과거), 자산을 늘리는가(미래)?**
- 부채 상환 → 주주 돈으로 채권자를 갚는 것. 주주 몫은 순수 감소.
- 시설 투자 → 주주 돈으로 미래 현금흐름을 사는 것. 가격이 적정하면 주주 몫 증가.

**혼합형은 반드시 항목별로 분해한다.** 시장은 혼합형을 종종 "가장 나쁜 항목의 색깔"로 통째 할인한다. 이때 좋은 항목은 미가격 상태로 남는다.

### 변수 2 — 수요 가시성: 지어놓으면 살 사람이 이미 있는가

증설형 유증의 성패를 실질적으로 가르는 변수. 강한 순서:

1. 고객사 장기공급계약(LTA)·선급금·캐파 예약 → **최강**
2. 고객사 퀄(승인) 통과 + 기존 라인 풀가동 + 수주잔고 증가
3. 산업 전체의 구조적 수요 전망 (리포트 수준)
4. 회사의 자체 시장 전망만 존재 → **거의 무의미**

> 판별 질문: "지금 라인은 몇 % 가동 중인가?"
> **기존 라인이 풀가동이 아닌 상태의 증설 증자는 대부분 실패한다.**

### 변수 3 — 희석 대비 성장

`d` (희석률) 대비 향후 2~3년 EPS 성장 기대. 실무 기준:

| 희석률 | 요구되는 이익 성장 |
|---|---|
| < 10% | 낮음. 웬만하면 소화 |
| 10~20% | 2년 내 이익 30% 이상 성장 필요 |
| 20~30% | 2년 내 이익 배증 수준 필요 |
| > 30% | 사실상 사업 구조 자체가 바뀌어야 함. 강한 경계 |

### 변수 4 — 시그널 (말이 아니라 행동)

회사와 시장이 남기는 **행동 증거**. 말(IR 자료)보다 훨씬 신뢰도가 높다.

| 신호 | 해석 |
|---|---|
| 최대주주 100% 참여 (또는 초과청약) | 강한 긍정 — 자기 돈을 넣는다 |
| 최대주주 불참·저조 | 강한 부정 — 지분 희석을 감수하고 안 넣는다 |
| **확정 발행가 > 최초 예정 발행가** | **강한 긍정** — 증자 진행 기간 중 주가가 올랐다는 하드 증거. 시장이 용도를 승인 |
| 확정 발행가가 예정가 대비 크게 하락, 조달액 축소 | 부정 — 시장이 계속 거부 |
| 실권율 높음 / 일반공모 미달 | 부정 |
| 금감원 정정요구, 신고서 효력정지 | 거버넌스 적신호. 단, **정정요구 뉴스 자체가 "악재 축소" 기대로 주가 촉매가 되기도 한다** |
| 공시 타이밍 조작 논란 | 사업과 별개의 독립 할인요인. 밸류에이션 멀티플을 눌러 놓는다 |

### 변수 5 — 사이클 위치 ★ 가장 흔한 함정

**업황 피크 부근의 증설형 유증은, 형태는 C형(증설)이지만 결과는 A형(생존)처럼 끝난다.**

캐파가 가동되는 시점(보통 공시 후 18~30개월)에 그 산업이 어디에 있을지가 진짜 질문이다.
- 사이클 초입 + 증설 → 캐파 가동 시점에 수요가 더 커져 있음 → `#희석돌파`
- 사이클 피크 + 증설 → 캐파 가동 시점에 판가 붕괴 + 산업 전체 과잉 → `#고점증자`

체크: **같은 산업의 다른 회사들도 동시에 증설 중인가?**
경쟁사가 일제히 증설 자금을 조달하고 있다면 그건 사이클 피크의 전형적 신호다.

---

## 5. 증설형인데도 실패하는 조건 (반례 경고)

형태만 보고 C형으로 분류하면 안 되는 경우:

1. **업황 피크 증설** — 캐파 가동 시점에 판가 붕괴 (`#고점증자`)
2. **범용 제품 증설** — 캐파는 늘지만 가격 결정력이 없어 마진이 따라오지 않음
3. **반복 증자** — 2~3년 내 2회 이상 조달. 자본이 밑 빠진 독 (`#반복증자`)
4. **기존 라인 미가동 상태의 증설** — 수요 없이 짓는 것
5. **희석률 30% 초과 + 수요 근거 부재**
6. **증설 자금인데 실제 집행이 지연·용도변경** — 증권신고서의 자금 집행 일정과 이후 정정공시를 대조할 것

## 6. 이 프레임의 결론 요약

```
유상증자를 봤을 때 순서:

1) 자금용도를 항목별로 쪼갠다        → 유형코드 (11_분류체계.md)
2) 각 항목에 수요 가시성을 매긴다     → 고객이 이미 있는가
3) 희석률과 페이백을 계산한다         → 숫자로 경주를 붙인다
4) 사이클 위치를 확인한다             → 캐파 가동 시점의 업황
5) T1 신호를 추적한다                → 발행가 궤적, 대주주 참여, 계획 변경

→ 5단계를 점수화한 것이 12_스코어카드.md
→ 시간이 없을 때의 축약판이 templates/QUICK_TRIAGE.md
```
