# 지수 편입 분류체계 — 유형코드 I1~I5

케이스 헤더의 `유형코드` 필드에 적는다. 역검색 1차 키.

---

## 1. 주분류 — 편입 외 스토리의 유무 ★

이 축 하나가 결과의 대부분을 설명한다.

| 코드 | 유형 | 정의 | 기본 기대 | 판별 질문 |
|---|---|---|---|---|
| **I1** | **덤 편입** | 편입과 무관한 실적·수주·기술 모멘텀이 이미 진행 중. 편입은 부수적 | **긍정** — P4를 넘긴다 | 편입 뉴스를 지워도 살 이유가 남는가? **예** |
| **I2** | **혼합** | 펀더멘털 개선과 편입 기대가 함께 작동 | 조건부 | 절반만 남는다 |
| **I3** | **순수 수급 편입** | 편입 기대가 상승의 사실상 유일한 재료 | **부정** — P3~P4에서 소진 | **아니오** |
| **I4** | **거품 편입** | **테마 급등으로 시총이 불어나 편입된 경우.** 편입이 거품의 *결과* | **강한 부정** — 편출 위험까지 | 시총이 실적으로 커졌나, 주가로 커졌나? |
| **I5** | **편출** | 지수에서 제외 | 부정 (기계적 매도) | — |

> **I4 경고**: 신규 상장 직후 급등으로 **특례편입**된 종목이 여기 해당할 위험이 가장 크다.
> 편입 자체가 "주가가 많이 올랐다"는 사실의 결과이므로, 편입은 **거품의 확인 도장**이지 근거가 아니다.

## 2. 부분류 — 지수와 경로

`I3-코스피200특례` 처럼 뒤에 붙인다.

| 지수 | 경로 |
|---|---|
| 코스피200 / 코스닥150 | `정기변경` (6월·12월) / `특례편입` (신규상장 15거래일 평균시총 50위 이내) |
| MSCI 한국 Standard | `정기리뷰` (2·5·8·11월, 5·11월이 반기 리뷰) |
| FTSE, KRX300 등 | 지수명 명시 |

## 3. 규모 부분류 — 선반영 정도 (P1 초과수익)

| 등급 | P1 초과수익 | 표기 | 해석 |
|---|---|---|---|
| 무선반영 | < 0%p | `N` | 편입 효과가 아직 남아 있을 수 있음 |
| 경미 | 0 ~ +20%p | `S` | |
| 상당 | +20 ~ +50%p | `M` | |
| 과열 | **> +50%p** | `L` | **P3 이후 반락 위험 매우 큼** |

**전체 표기 예시**: `I4-코스피200특례-L`, `I1-MSCI정기리뷰-N`

## 4. 2축 매트릭스

| ↓유형 \ P1 선반영→ | **무선반영 (N)** | **상당 (M)** | **과열 (L)** |
|---|---|---|---|
| **I1 덤 편입** | 🟢 최적 | 🟢 양호 | 🟡 스토리는 남지만 단기 부담 |
| **I2 혼합** | 🟡 | 🟡 | 🔴 |
| **I3 순수 수급** | 🟡 편입일 효과만 | 🔴 | 🔴 |
| **I4 거품** | 🔴 | 🔴 | 🔴 **강한 부정 + 편출 위험** |

## 5. 분류 실전 예시

### 에코프로머티리얼즈 2023-12 (코스피200 특례편입)

| 항목 | 내용 |
|---|---|
| 편입 사유 | 2023-11-17 상장 후 **급등으로** 15거래일 평균 시총 50위 진입 |
| 편입 외 스토리 | **없음.** 전구체 사업의 실적 근거가 주가를 설명하지 못함 |
| P1 초과수익 (상장 → 발표일) | **+133.0%p** (15거래일) |
| **유형코드** | **`I4-코스피200특례-L`** |
| 결과 | 편입 후 고점(2024-01-10) 이후 **RS 407.7 → 21.0** |

→ **I4 × L** = 매트릭스 최악 칸. 실제로 최악으로 끝났다.

### 알테오젠 2024-05 (MSCI 정기리뷰)

| 항목 | 내용 |
|---|---|
| 편입 사유 | 2024-02 **머크 키트루다SC 제형 독점계약**으로 시총 급증 → 편입 요건 충족 |
| 편입 외 스토리 | **강함.** ALT-B4 기술 라이선스, 마일스톤·로열티 |
| P1 초과수익 (기대 형성 → 발표 전일) | **-8.7%p** (기대가 주가를 올리지 못함) |
| **유형코드** | **`I1-MSCI정기리뷰-N`** |
| 결과 | 편입 후 RS 292까지 상승. 이후 조정도 **편입이 아니라 특허 이슈** 때문 |

→ **I1 × N** = 매트릭스 최적 칸. 다만 **편입이 좋아서가 아니라 편입이 상관없어서** 좋았다.

---

## 6. 이 분류가 말하는 것

> 지수 편입은 **독립변수가 아니라 종속변수**인 경우가 많다.
> 시총이 커져서 편입되는 것이므로, "왜 시총이 커졌는가"가 진짜 질문이다.
> **실적으로 커졌으면 I1, 주가로만 커졌으면 I4.**
