# QUICK TRIAGE — 신규 유상증자 이슈 15분 판정

새 공시가 떴을 때 이것부터. 깊은 케이스 작성 여부는 이 결과로 정한다.

---

## STEP 1 — 4문항 (5분)

DART 「주요사항보고서(유상증자결정)」 하나만 열어도 답할 수 있다.

| # | 질문 | YES | NO |
|---|---|:--:|:--:|
| 1 | **돈이 미래로 가는가?** (시설자금·타법인취득 vs 채무상환·운영자금) | ☐ | ☐ |
| 2 | **그 미래에 고객이 이미 있는가?** (기존 라인 풀가동 / LTA / 수주잔고 증가) | ☐ | ☐ |
| 3 | **희석률이 20% 미만인가?** (신주수 ÷ 증자후 총주식수) | ☐ | ☐ |
| 4 | **업황이 사이클 초·중반인가?** (피크 통과가 아닌가) | ☐ | ☐ |

**판정**
- YES 4개 → **C형 우량 후보.** 전체 케이스 작성 대상. 스코어카드로 진행.
- YES 3개 → **조건부.** NO가 나온 항목이 이 건의 핵심 리스크. 그 항목만 집중 추적.
- YES 2개 이하 → **보류.** 전체 케이스 작성 불필요. `INDEX.md` 대기 목록에 한 줄만 남긴다.

> 1번이 NO면 나머지가 다 YES여도 C형이 아니다. 1번은 필수 관문.

---

## STEP 2 — 혼합형 분해 (5분)

「자금조달의 목적」 표에 항목이 2개 이상이면 반드시 쪼갠다.

| 항목 | 금액 | 비중 | 코드(A~F) |
|---|---|---|---|
| | | | |

**핵심 질문**: 시장이 지금 **가장 나쁜 항목의 색**으로 전체를 할인하고 있는가?
- YES → `#악재분해` 후보. **그 나쁜 항목이 제거·축소될 가능성**을 별도로 추적한다. (미가격 옵션)
- 추적 방법: 정정신고서, 금감원 정정요구, 계약 해제 공시, 소액주주·기관 반발 강도

---

## STEP 3 — 즉시 확인할 적신호 (5분)

하나라도 걸리면 등급 강등.

- [ ] 최근 3년 내 2회 이상 조달 → `#반복증자`
- [ ] 기존 라인 가동률이 풀이 아님
- [ ] 회사가 증설 캐파·기대매출·완공시점을 제시 못함
- [ ] 자금 사용목적에 `채무상환자금`이 섞여 있음
- [ ] 장 마감 후 기습 공시 / 호재와 악재의 공시 시점 분리 → `#공시신뢰훼손`
- [ ] 경쟁사 3곳 이상 동시 증설 조달 중 → `#고점증자`

## STEP 4 — 과거 사례 역검색 (즉시)

```bash
# 같은 유형코드
grep -rn "유형코드" cases/ | grep "C("

# 같은 패턴
grep -rl "#악재분해" cases/
grep -rl "#고점증자" cases/

# CSV에서 결과 통계
column -s, -t data/cases.csv
```

`INDEX.md`의 **태그 역인덱스**에서 같은 태그를 가진 케이스를 열어
`9. 이식 가능한 규칙` 섹션만 읽는다. 그게 가장 빠른 판단 근거다.
