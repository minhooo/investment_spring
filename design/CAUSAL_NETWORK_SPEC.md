# 통합 인과망과 시계열 검증 계약

구현 기준: 2026-09-09. 운영 화면: https://investment-spring.vercel.app/causal-network.html

## 목적과 현재 구현

사용자가 점수를 임의로 매기는 부담을 줄이고, 거시 인과지도에서 연구한 관계의 근거를 재현한다. 현재 **10개 거시 경로와 123개 원문 변수**를 등록한다. 사례 탐색의 종목·이슈·테마·사례 카드는 통합망 범위가 아니다. **그래프 연결, 경제적 인과 가설, 통계적 선행 예측**은 다른 의미다. 이번 구현은 관측 자료 기반 탐색이며 구조적 인과 추정이나 매매 모델이 아니다.

- 거시 경로 → 변수들을 연결. 노드 순서를 읽어 인과를 추측하지 않고 `relations.json`에 명시한 관계만 방향 화살표를 만든다.
- 서로 다른 경로는 명시적 `bridges`를 통해 연결한다. 지역 도매 전력가격과 한국 요금, 범용 메모리와 HBM을 동일 변수로 병합하지 않는다.
- 통계 후보는 별도 선이다. 경로 가설을 통계 결과로 자동 덮어쓰거나 후보가 0개일 때 임계값을 자동 완화하지 않는다.

## 화면: CSS, 2D, 3D의 역할

현재 운영 전 화면 단계는 **가상 데이터 기반 거시 네트워크 캔버스 MVP**다. CSS는 헤더·안내 패널·노드 인스펙터·반응형 drawer를 담당하고, 노드 배치와 선택·드래그·팬·줌은 로컬 포함한 **Cytoscape.js 3.33.1 / Canvas 2D**가 담당한다. 외부 CDN 장애로 그래프가 사라지지 않도록 라이브러리와 MIT 라이선스를 `tools/vendor/`에 보관하고 빌드 시 인라인한다.

- 화면 내부의 12개 노드·14개 관계는 상호작용 검증용 가상 예시다. `DEMO DATA`, `검증 전`을 명시하며 운영 관측값·통계 결과로 취급하지 않는다.
- 긍정 관계는 초록 실선과 `+`, 부정 관계는 분홍 점선과 `−`, 모든 방향 관계는 삼각 화살촉으로 표시한다.
- 노드 선택 시 방향 그래프를 순회해 전체 선행 원인과 후행 영향을 각각 강조하고, 관련 없는 요소는 흐리게 표시한다. 엣지 hover에는 관계 설명을 표시하며 클릭·탭하면 선택 관계와 원인·결과 노드만 강조하고 그 외 요소를 흐리게 표시한다.
- Node Detail Panel v1은 선택 노드의 역할·ID·정의와 가상 값·단위·기준 시점·관측 주기·지역·분류·한 문장 해석을 표시한다. 직접 상위 원인과 직접 하위 영향은 원인→결과·부호·설명을 가진 버튼으로 제공하며 선택하면 해당 노드로 그래프와 패널이 함께 이동한다. 이 메타데이터도 상호작용 검증용 가상 예시이며 공식 관측값이 아니다.
- Edge Detail Panel v1은 선택 관계의 원인→결과, 긍정/부정 부호, 전달 메커니즘, 성립 조건, 완충·반대 요인과 가상 전달 시차를 표시한다. 원인 노드와 결과 노드로 이동하는 버튼은 노드 선택 모드로 전환하고 그래프 중심과 Node Detail을 함께 갱신한다. 엣지 ID는 `edge` URL 파라미터에 보존하며 `node`와 동시에 사용하지 않는다.
- Causal Path Explorer v1은 시작 노드와 결과 노드 사이에서 가상 방향 관계만 따라가는 가장 짧은 경로 한 개를 BFS로 선택한다. 경로 노드·엣지는 강조하고 경로 밖 요소는 흐리게 표시하며 오른쪽 패널에서 단계별 원인→결과·부호·관계 설명, 이전/다음 단계와 전체 경로 맞춤을 제공한다. 선택 경로는 `from`·`to` URL 파라미터로 복원한다. 경로 길이나 단계 선택은 영향 강도·확률·투자 점수가 아니다.
- 1024px 이하 상세 패널은 오른쪽 drawer로 열고 Tab 순환·Escape 닫기·열기 버튼 포커스 복귀를 제공한다. 모바일은 hover 없이 엣지 tap 또는 왼쪽 drawer의 시작/결과 선택으로 같은 상세를 열며, 경로 실행 후 오른쪽 drawer로 전환한다. 최초 URL 복원에서는 선택 상태만 준비하고 drawer는 자동으로 열지 않는다.
- 인증·데이터베이스·뉴스·AI·백테스트·충격 시뮬레이션·자동 모형 실행·공식 기준 변경은 현재 화면 범위가 아니다.
- 빌더는 정식 거시 payload와 실행 스냅샷을 계속 재현하지만 MVP 캔버스의 렌더링 입력으로 쓰지 않는다. 가상 관계는 `relations.json`에 병합하지 않는다.

### 정식 데이터 연결 후 적용할 화면 계약

1. 군집 개요: 10개 거시 경로를 데스크톱 최대 4열, 좁은 화면 최대 2열의 중앙 집중형 고정 배치로 표시한다. 마지막 행의 적은 노드는 행 중앙에 둔다. 거시 경로는 세 보기 모두 보라색 둥근 사각형, 경제 변수는 세 보기 모두 파란색 원을 사용해 보기 전환으로 계위의 도형·색이 바뀌지 않게 한다. 개요에서는 앞·뒤 핵심어를 남긴 2줄 축약 라벨과 변수 개수를 사용하며 전체 명칭은 선택기와 상세 패널에서 보인다. 군집 사이의 명시적 가설 연결은 유지한다.
2. 주변 연결: 선택 노드로부터 1·2단계. 선택 노드를 첫 행에 두고 그래프 거리별 노드를 다음 행들에 배치하는 고정 계층형 격자를 사용한다. 자동 맞춤 배율은 1배를 넘기지 않고, 좁은 화면의 작은 부분망은 1열, 큰 부분망은 2열, 넓은 화면은 3–4열로 배치한다. 필요한 경우 그래프 높이를 늘려 라벨을 축소하거나 겹치게 하지 않는다. 소속/가설/통계 레이어를 각각 선택한다.
3. 전체 상세: 현재 전체 노드. 미충족 통계 관계는 기본 숨김, 사용자가 선택하면 표시한다.
4. 연결 클릭: 원인·결과, 근거, 가설의 조건, 통계의 표본·구간·계수·검정·탈락 기준.
5. 그래프 접근이 어려운 경우 변수 선택기와 연결 목록으로 같은 정보를 이용한다.

위치·중심성·군집간 거리는 영향 강도나 투자 점수가 아니다. 연결 수가 증가할 때 **연결을 줄여서 탐색하는 설계**가 핵심이다. 3D는 가림, 시점 조작, 깊이 해석과 한글 라벨 읽기 비용 때문에 기본 화면으로 채택하지 않았다. WebGL은 2D에도 쓸 수 있다.

### 향후 적용 규칙

현재 거시 원문 범위의 화면을 검증했으며 수만 노드 성능을 보장하지 않는다. 노드/연결 수, 초기 렌더 시간, 팬·줌 지연, 메모리를 측정한 뒤 WebGL 2D, 서버 부분 그래프 조회, 레이아웃 워커를 도입한다. 3D는 관계 분석의 품질을 올린다는 사용자 검증이 있을 때 보조 보기로만 검토한다. 그래프 저장 스키마는 렌더러와 독립적이므로 교체 가능하다.

## 통계 모형과 데이터

`tools/network_analysis.py`는 설명 가능한 ARX 형태의 분포시차 회귀를 사용한다.

`Y_t = 절편 + Y의 과거 수익률 + 대상 시장의 과거 수익률 + X의 과거 수익률 + 오차`

제한 모형은 마지막 X 항을 제외한다. 고정 시차의 X 계수가 모두 0인지 훈련 자료에서 HAC 공분산 Wald 검정한다. 이는 시장 시차를 통제한 Granger 방식의 **추가 선행 예측력 검사**다. X→Y의 구조적 인과로 해석하지 않는다.

현재 데이터:

- 첫 증분 병합 `cm-20260909-001`은 대기 18건과 인접 경로만 검토했다. 카드 12건은 일부 채택·기존 조건 보강, 6건은 보류이며 카드별 미편입 항목은 `data/causal/merges/cm-20260909-001.md`와 JSON 기록에 남긴다. 신규 변수 9개·가설 9개를 추가해 총 133개 노드·152개 가설·123개 소속 관계다. 시계열·정책 기준은 바꾸지 않는다.
- 일본 수입물가(엔화 기준 월별 지수)와 일본 전국 종합 CPI(월별 전년비)는 기존 글로벌 물가와 별도 노드다. USD/JPY의 달러 결제 환산비용과 실제 소매가격 전가를 구분하며, 일본은행 전망의 신선식품 제외 CPI를 종합 CPI 관측값으로 쓰거나 자동 정책금리 인상선으로 연결하지 않는다.
- LLM·전력 경로의 미국 프로젝트 금융 분기는 계약상 신용보강 → 인출 가능한 금융여력 → 기존 착공 노드와, 고객 현금회수 부족 → 부도·차환 위험 → 유효 보증의 지급 부담을 분리한다. 전력비·차환비용은 해당 시설의 계약·헤지·현금완충 조건에서만 부족액으로 연결한다. 지분투자·클라우드 크레딧·기업 전체 runway·최종손실을 같은 노드로 합치지 않으며 한국 주택에서 미국 AI로 직접 연결하지 않는다.
- 장기금리 경로의 재무부 유동성 지원 바이백 → 비지표물 유동성은 정기적인 매도 기회에 관한 가설이다. 현금관리 바이백·TGA–준비금 회계·QE·구조적 장기채 수요·금과 비트코인 가격과 분리한다. 프로그램 목적은 효과의 실증 증명이 아니며 실제 낙찰·결제·동시 발행과 CUSIP별 호가를 확인한다.
- 거시 경로의 노드·설명·조건·한계와 `relations.json`의 명시적 가설.
- 범용 메모리 경로는 HBM·고부가 제품 우선 생산배분, 고객의 선구매·장기공급계약·재고 축적, PC·스마트폰 실수요와 재고조정, 중국 업체의 투자 결정과 적격 양산을 서로 다른 변수로 둔다. Micron의 2026년 3분기 10-Q와 2025년·2023년 10-K, CXMT·YMTC의 거래소 공시를 근거로 생산배분→비HBM 공급제약, 재고→주문 조정, 가격·수익성→투자→시차를 둔 유효공급의 조건부 순환을 기록한다. 업로드 원문의 조선업 역사 반복, 중국의 의도적 가격조작, 특정 폭락 시점은 검증 가능한 인과선으로 채택하지 않는다.
- 장기국채금리는 기대 단기금리 경로와 기간프리미엄으로 분해한다. 장기채 순공급·듀레이션은 기간프리미엄에 같은 방향, 중앙은행·외국·연기금·보험의 구조적 장기채 수요는 반대 방향 가설로 둔다. 유가 상승은 기대인플레이션과 중앙은행 반응 기대를 높이는 조건에서만 기대 단기금리 경로와 연결한다. 약정 현금흐름이 같은 기존 고정금리 장기채는 시장 요구수익률 상승과 가격이 반대로 움직이는 관계를 별도 노드로 두며, 만기 상환 약정과 중도 시장가격·기회비용·재투자·인플레이션·부도 위험을 구분한다. 한국 국채선물은 현물채권 보유와 분리해 가격, 상품·계좌별 증거금률, 실제 포지션 규모로 계산한 실효 레버리지, 일일정산 손실·현금유출, 추가증거금·포지션 축소 압력의 다섯 노드로 둔다. 특정 날짜의 증거금률을 고정 배율로 일반화하거나 차근월물 가격차를 보장된 롤 수익으로 해석하지 않는다. 선물 손실에서 금융시장 파이어세일로의 연결은 혼잡한 기관 포지션과 실제 현물·헤지자산 매도가 확인될 때만 성립하는 조건부 가설이다.
- 미국 소형주 분기는 차환비용에서 소형기업의 이자비용·차환 부담, 투자·현금흐름·이익 하락 압력, Russell 2000의 대형주 대비 상대성과 하방 압력을 순서대로 분리한다. 기업별 변동금리 비중·만기벽·이자보상배율이 악화되고 그 영향이 지수 구성기업 전반의 이익 추정치에 반영될 때만 이어지는 조건부 가설이며, Russell 2000을 고부채 기업만의 바스켓으로 보지 않는다. E-mini RTY와 Micro M2K의 계약승수 차이는 실제 계좌 위험이나 안전자금 기준이 아니고, 원월물 고가를 매도 롤의 보장 수익으로 해석하지 않는다. 인버스 ETF의 일일 재설정·경로의존성도 원금 자동 소멸로 일반화하지 않는다.
- 한국 주택 PF 경로는 기존 주택가격, 사업장별 분양률·분양수입·공사비·금융비용, 시행사·SPC 상환불능 위험을 분리한다. PF-ABCP·ABSTB 차환, 증권사 매입확약·시공사 보증, HUG·주금공·지자체 보증도 계약과 책임주체가 달라 별도 노드로 둔다. 손실·충당금과 단기 유동성 부족, 자산매각·신용축소, 회사채·CP·RP 시장 확산을 단계별 가설로 연결하고 정책 유동성·공적 보증·사업장 재구조화·정리는 신용손실 제거가 아닌 완충 경로로 표시한다. 2022년 레고랜드 사례는 보증 신뢰 충격과 단기시장 전이의 관측 사례이지 모든 부동산 하락이 금융위기로 이어진다는 일반 법칙으로 사용하지 않는다.
- 엔 캐리는 미·일 단기금리 차이와 USD/JPY 변동성을 캐리의 위험조정 매력에서 함께 보고, 엔화 조달 익스포저·환율·청산·대상통화 및 위험자산 매도를 분리한다. 금리차와 스왑포인트를 확정수익으로 보지 않으며, 은행대출·FX스왑·선물·리테일 마진 거래를 하나의 총량으로 합치지 않는다. 청산에서 한국 주가로 가는 연결은 실제 투자대상·교차자산 매도·위험프리미엄이 확인될 때만 성립하는 조건부 가설이다. 현지통화 지수와 달러 환산 수익률의 차이는 산술적 환산 관계로 별도 관측 노드에 기록하고 인과 화살표를 만들지 않는다. 코스피·니케이·환율의 동조화는 지수 수준이 아닌 동기화한 수익률로 표본 주기·구간·휴장·시차를 명시해 검정하며, 높은 구간 상관이나 장중 선후관계만으로 직접 인과나 대체투자를 확정하지 않는다.
- 미국 교차상장 경로는 거래소 교차상장·스폰서드 ADR, 미국 투자자의 거래 접근성, 종목별 보유, 공시·투자자 보호, 2차시장 유동성·가격 발견, 주식 요구수익률을 분리한다. SEC의 ADR 구조와 미 연준의 교차상장 보유 연구를 근거로 접근성 개선 가능성은 채택하되, ADR 가격은 원주와 전환비율에 연결되고 상장기업 자기선택·상장비용·환율·예탁수수료가 남는다고 명시한다. 미국 재정적자→무역적자→특정국 달러예금→특정 미국 주식 매수, 스테이블코인 확산→미국 주식 급락·비트코인 급등은 회계관계와 자산배분 선택을 단방향 인과로 합친 주장이라 가설선으로 채택하지 않는다.
- 한국 자사주·지수 수급 경로는 취득 이사회 결의와 실제 장내 체결, 거래대금·호가 대비 매수 강도, 해당 종목의 단기 가격 지지 압력, 시가총액 가중 KOSPI 기여, 프로그램 종료, 취득 후 소각·임직원 보상·보유·처분을 분리한다. DART의 SK하이닉스 2026년 8월 19일 취득·소각 공시와 삼성전자 8월 21일 임직원 보상 목적 취득 공시를 기준으로 발표액과 체결액, 기타법인 순매수 전체를 같은 값으로 보지 않는다. 실제 자사주 집행 연구는 시장·제도에 따라 유동성 효과가 엇갈리므로 가격 하한이나 무조건 상승을 표시하지 않는다. 매입 종료는 반복 매수의 제거이지 매도로의 전환이 아니며, 남은 매도 불균형·낮은 유동성·새 부정 정보 없이 코스피 급락을 예측하는 선은 만들지 않는다. 2026년 9월 4일 솔리다임 재공시는 확정된 사항이 없다고 밝혔으므로 IPO 발표·중복상장 충격도 가설선으로 채택하지 않는다.
- 중동 충돌 경로는 원유 생산·수송 위험과 호르무즈 LNG 수송위험을 분리한다. LNG 위험은 실제 항행·선적·보험·운임 또는 물량 차질이 확인되고 대체 LNG·파이프라인·저장·수요감축이 부족할 때만 유럽 TTF 상승 압력으로 연결한다. TTF는 유가·석탄과 합치지 않고 `EUR/MWh`, 현물/기준월물, 관측일을 고정한다. 유럽 가스→지역 도매 전력가격은 가스발전이 한계가격을 정하는 시간대·입찰구역에서만, 전력가격→AI 채산성은 시장연동 계약 또는 갱신 PPA가 실제 데이터센터 전력비를 높일 때만 성립한다. 장기 PPA·연료 헤지·가격상한·저탄소 발전믹스·효율 개선·자가전원·지역 이전을 완충 조건으로 기록하며 `AI 산업 붕괴`로 일반화하지 않는다. 가스→기대 단기금리 경로도 중기 기대인플레이션과 중앙은행 반응이 바뀌는 경우로 제한하고 영국 10년물→미국 10년물 직접 인과선은 만들지 않는다. 업로드 글의 TTF 전년 대비 130%, 특정 고점·금리 수준은 계약·통화·관측일을 재현하지 못해 공식 관측값으로 등록하지 않았다.
- 비교 가능한 거시 노드별 시계열은 아직 등록하지 않았다. 기존 FRED 유가·환율 파일과 사례 종목 수정주가는 이 화면의 변수를 완전하게 대변하지 않으므로 사용하지 않는다.
- 거시 요금·AI CAPEX·HBM 계약가격·부동산·고용·임금 등을 포함한 계열은 빈도·단위·지역·공개시점(vintage)을 명시해 별도 등록한 뒤에만 검정에 쓴다.

전처리:

1. 컷오프까지 완료된 금요일 주만 사용하고 주간 마지막 유효 수준을 로그 차분한다.
2. 수준 값이 0 이하이거나 결측이면 사용하지 않는다. 임의 보간·앞뒤 채우기는 하지 않는다.
3. 소스 실제 관측 간 간격이 기준보다 긴 주간 수익률은 제외한다.
4. 금요일 캘린더에 재색인한 뒤 shift하고 결측을 제거한다. 결측 주를 삭제해서 앞뒤 주가 붙는 오류를 방지한다.
5. 미국 자료는 이미 종료된 과거 주 값만 사용한다. 같은 날 미국 종가로 그날 KRX 종가를 예측하지 않는다. 다만 정확한 발표 시각은 아직 복원하지 않았다.

검증 가족은 거시 계열이 등록되기 전에 `relations.json`의 명시적 가설 중 측정 정의가 완성된 관계로 사전 정의한다. 결과가 좋아 보이는 쌍만 사후 선택하지 않는다. 현재는 등록된 비교가 0건이므로 후보·유의성·오차 개선을 표시하지 않는다.

기본 `policy.json`:

| 항목 | 기본값 | 의미 |
|---|---|---|
| 주기/시차 | 주간 / 2주 | 시차별 p값을 훑어 최솟값을 고르지 않음 |
| 최소 공통 관측 | 80주 | 부족하면 점수 없이 제외 |
| 최초 훈련 | 앞 60% | 무작위 분할 없음 |
| 미래 검증 | 이후 4구간 | 구간마다 그 이전 자료로 재학습, 한 주 앞 예측 |
| 정상성 | 훈련 ADF p≤0.05 | 미통과 시 제외; ADF 통과도 정상성의 보장은 아님 |
| 다중검정 | BH q≤0.05 | 제외 관계는 보수적으로 p=1로 검사 가족에 포함 |
| 예측 개선 | RMSE 2% 이상 감소 | 단순 시차 통제 모형 대비 추가 예측력 |
| 개선 구간 | 4개 중 75% 이상 | 한 구간에만 의존하지 않음 |
| 방향 안정 | 75% 이상 | 초기 훈련 시차계수 합과 재학습 계수합의 부호 일치 |

이 숫자는 **공개된 탐색 기본값**이지 최적값·확률·학계의 보편적 권장값이 아니다. BH의 보장은 검정 간 의존 구조에 제약이 있고 시장 자료의 모든 의존성을 해결하지 않는다. 95% HAC 계수구간은 개별 관계의 명목 구간으로 전체 다중검정 동시 구간이 아니다. 시차계수 합은 구조적 충격반응함수·경로별 금전 영향이 아니다.

## 판단 변경과 감사

- 종합점수 대신 기준별 수치와 충족/미충족 이유를 보인다. 계수 크기(효과), q(검정), RMSE(예측), 부호 안정성을 합산하지 않는다.
- 브라우저에서는 네 판정 임계값만 변경할 수 있다. 변경 이유·시각·이전/이후 값·실행 ID를 기록한다. 모형을 재학습했다고 표현하지 않는다.
- 초안은 실행 ID별 localStorage에만 보관한다. 다른 브라우저·다른 실행 결과로 자동 전파하지 않으며 운영 기준은 바뀌지 않는다. 내보내기는 다운로드다.
- 학습 기간·시차·입력·기준 변경 후 재계산은 `--policy`, `--as-of`로 수행한다. 채택하려면 원본 `policy.json`을 검토해 갱신하고 이유·버전을 올린 뒤 새 배포를 실행한다.
- 검증 보고서는 원본 기준·수정 초안·개별 결과·모형 버전·입력 SHA-256·환경 버전·변경 이력을 포함한다. `data/causal/runs/<run-id>.json`은 거시 범위의 재현용 로컬 스냅샷이다. 같은 ID에서 내용이 다르면 빌드가 실패한다.
- 가설의 수정은 `relations.json`의 sign/mechanism/bridges를 고치고 다시 빌드한다. 기존 설명 원문은 거시 상세에서 읽으며 해당 HTML 내용 해시도 포함한다.
- `relations.json`의 선택적 `hypothesis_notes`는 기존 `hypothesis:<원인>:<결과>` ID에 근거·조건·한계·시차 설명을 덧붙인다. 경로와 bridge의 유형·부호를 바꾸지 않으며, 없는 ID나 빈 설명은 빌드 오류다. 새 증분 가설은 이 설명 또는 bridge 본문과 양 끝 상세를 함께 기록한다. 서로 다른 조건·부호의 관계를 같은 ID로 억지 병합하지 않는다.
- 후보가 바뀌어도 기존 과거 스냅샷은 남긴다. 현재 브라우저 UI는 다른 실행 사이의 자동 비교까지 제공하지 않는다.

```powershell
python -m venv .venv-network
.venv-network/Scripts/python.exe -m pip install -r requirements-network.txt
.venv-network/Scripts/python.exe tools/test_network_analysis.py
.venv-network/Scripts/python.exe tools/test_causal_network_scope.py

.venv-network/Scripts/python.exe tools/build_causal_network.py --policy path/to/causal-policy-draft.json --as-of 2026-09-04
python tools/deploy_dashboard.py
```

기본 운영 배포는 공식 `data/causal/policy.json`으로 다시 계산한다. `--as-of`는 최신 수정본을 날짜로 자르는 기능이며 시점별 vintage 복원이 아니다. 별도 기준 실험은 로컬 HTML에 반영되지만 공식 기준을 채택하지 않고 운영 배포하면 공식 기준으로 돌아간다. 과거 원본 CSV를 교체하면 해시만으로 그 원본을 복구할 수 없으므로 데이터 저장소에 원본 버전도 보관해야 한다.

## 향후 적용 규칙: 장기 전달과 신경망

월/분기 주기·공개 시차·계절조정·실질/명목 구분·빈티지 테이블을 구축한 뒤 별도 모형으로 확장한다. 가격은 로그차분, 금리는 %p 차분을 검토하며 수준의 공적분이 확인되면 VECM을 고려한다. 이 장기 모형은 이번 주간 가격 검사와 혼합하지 않는다.

다변량 VAR/국소투영, PCMCI, 변화점·국면별 모형은 미구현이다. PCMCI도 관측되지 않은 공통 원인·정상성 등의 가정이 필요하다. LSTM/TCN/GNN은 충분한 표본이 생기면 단순 모형 대비 out-of-sample 성능으로 채택하며, attention/가중치를 인과 강도로 보이지 않는다. 그래프의 순환은 시간 지연이 있는 관계로 저장하고 미래의 영향 전파 엔진은 같은 충격의 중복 계산을 방지해야 한다. 현재는 숫자 충격을 가설망 전체에 곱해 전파하지 않는다.
