# 통합 인과망과 시계열 검증 계약

구현 기준: 2026-09-08. 운영 화면: https://investment-spring.vercel.app/causal-network.html

## 목적과 현재 구현

사용자가 점수를 임의로 매기는 부담을 줄이고, 모든 사례를 탐색하면서 관계의 근거를 재현한다. 기존 6개 거시 경로와 포털의 모든 사례를 자동 등록한다. **그래프 연결, 경제적 인과 가설, 통계적 선행 예측**은 다른 의미다. 이번 구현은 관측 자료 기반 탐색이며 구조적 인과 추정이나 매매 모델이 아니다.

- 기존 사례 → 공통 종목 주가·테마·이슈에 연결. 같은 종목의 두 사례는 별도 사례 ID를 유지하며 하나의 주가 변수를 공유한다.
- 거시 경로 → 변수들을 연결. 노드 순서를 읽어 인과를 추측하지 않고 `relations.json`에 명시한 관계만 방향 화살표를 만든다.
- 서로 다른 경로는 명시적 `bridges`를 통해 연결한다. 지역 도매 전력가격과 한국 요금, 범용 메모리와 HBM을 동일 변수로 병합하지 않는다.
- 통계 후보는 별도 선이다. 경로 가설을 통계 결과로 자동 덮어쓰거나 후보가 0개일 때 임계값을 자동 완화하지 않는다.

## 화면: CSS, 2D, 3D의 역할

CSS는 헤더·필터·상세 패널·반응형을 담당한다. 노드 배치와 선택·드래그·확대는 로컬 포함한 **Cytoscape.js 3.33.1 / Canvas 2D**가 담당한다. 외부 CDN 장애로 그래프가 사라지지 않도록 라이브러리와 MIT 라이선스를 `tools/vendor/`에 보관하고 빌드 시 인라인한다.

1. 군집 개요: 테마·이슈·거시 경로와 소속 개수, 군집 사이의 명시적 가설 연결.
2. 주변 연결: 선택 노드로부터 1·2단계. 소속/가설/통계 레이어를 각각 선택한다.
3. 전체 상세: 현재 전체 노드. 미충족 통계 관계는 기본 숨김, 사용자가 선택하면 표시한다.
4. 연결 클릭: 원인·결과, 근거, 가설의 조건, 통계의 표본·구간·계수·검정·탈락 기준.
5. 그래프 접근이 어려운 경우 변수 선택기와 연결 목록으로 같은 정보를 이용한다.

위치·중심성·군집간 거리는 영향 강도나 투자 점수가 아니다. 연결 수가 증가할 때 **연결을 줄여서 탐색하는 설계**가 핵심이다. 3D는 가림, 시점 조작, 깊이 해석과 한글 라벨 읽기 비용 때문에 기본 화면으로 채택하지 않았다. WebGL은 2D에도 쓸 수 있다.

### 향후 적용 규칙

126개 노드의 실제 화면을 검증했으며 수만 노드 성능을 보장하지 않는다. 노드/연결 수, 초기 렌더 시간, 팬·줌 지연, 메모리를 측정한 뒤 WebGL 2D, 서버 부분 그래프 조회, 레이아웃 워커를 도입한다. 3D는 관계 분석의 품질을 올린다는 사용자 검증이 있을 때 보조 보기로만 검토한다. 그래프 저장 스키마는 렌더러와 독립적이므로 교체 가능하다.

## 통계 모형과 데이터

`tools/network_analysis.py`는 설명 가능한 ARX 형태의 분포시차 회귀를 사용한다.

`Y_t = 절편 + Y의 과거 수익률 + 대상 시장의 과거 수익률 + X의 과거 수익률 + 오차`

제한 모형은 마지막 X 항을 제외한다. 고정 시차의 X 계수가 모두 0인지 훈련 자료에서 HAC 공분산 Wald 검정한다. 이는 시장 시차를 통제한 Granger 방식의 **추가 선행 예측력 검사**다. X→Y의 구조적 인과로 해석하지 않는다.

현재 데이터:

- `data/prices/`의 종목 수정주가와 해당 파일의 비교지수.
- `data/macro/DCOILBRENTEU.csv`, `DEXKOUS.csv`의 FRED 원유·환율 관측.
- 중복 원본은 `series_overrides.json`으로 선택. 삼성바이오는 분할 후 자료를 사용해 다른 경제적 실체를 잇지 않는다. 원주가·수정주가는 중복 사용하지 않는다.
- 현재 수정본이며 vintage·실제 발표/수정 시점이 없다. 소스 해시는 재현에 쓰지만 과거 공개 당시 자료였음을 보장하지 않는다.
- 거시 요금·AI CAPEX·HBM 계약가격·부동산·고용·임금 등은 현재 계열 미등록. 유가·환율 대리변수를 이들 계열의 실제 관측으로 대신하지 않는다.

전처리:

1. 컷오프까지 완료된 금요일 주만 사용하고 주간 마지막 유효 수준을 로그 차분한다.
2. 수준 값이 0 이하이거나 결측이면 사용하지 않는다. 임의 보간·앞뒤 채우기는 하지 않는다.
3. 소스 실제 관측 간 간격이 기준보다 긴 주간 수익률은 제외한다.
4. 금요일 캘린더에 재색인한 뒤 shift하고 결측을 제거한다. 결측 주를 삭제해서 앞뒤 주가 붙는 오류를 방지한다.
5. 미국 자료는 이미 종료된 과거 주 값만 사용한다. 같은 날 미국 종가로 그날 KRX 종가를 예측하지 않는다. 다만 정확한 발표 시각은 아직 복원하지 않았다.

검증 가족은 사전 정의한다: 유가·환율→보유 종목 전부, 공통 테마가 있는 종목 쌍의 양방향. 결과가 좋아 보이는 쌍만 사후 선택하지 않는다. 테마 선정 자체는 현재 메타에 의존하므로 생존자·선택 편향이 남는다.

기본 `policy.json`:

| 항목 | 기본값 | 의미 |
|---|---|---|
| 주기/시차 | 주간 / 2주 | 시차별 p값을 훑어 최솟값을 고르지 않음 |
| 최소 공통 관측 | 80주 | 부족하면 점수 없이 제외 |
| 최초 훈련 | 앞 60% | 무작위 분할 없음 |
| 미래 검증 | 이후 4구간 | 구간마다 그 이전 자료로 재학습, 한 주 앞 예측 |
| 정상성 | 훈련 ADF p≤0.05 | 미통과 시 제외; ADF 통과도 정상성의 보장은 아님 |
| 다중검정 | BH q≤0.05 | 제외 관계는 보수적으로 p=1로 검사 가족에 포함 |
| 예측 개선 | RMSE 2% 이상 감소 | 단순 시차 통제 모형 대비 추가 예측력 |
| 개선 구간 | 4개 중 75% 이상 | 한 구간에만 의존하지 않음 |
| 방향 안정 | 75% 이상 | 초기 훈련 시차계수 합과 재학습 계수합의 부호 일치 |

이 숫자는 **공개된 탐색 기본값**이지 최적값·확률·학계의 보편적 권장값이 아니다. BH의 보장은 검정 간 의존 구조에 제약이 있고 시장 자료의 모든 의존성을 해결하지 않는다. 95% HAC 계수구간은 개별 관계의 명목 구간으로 전체 다중검정 동시 구간이 아니다. 시차계수 합은 구조적 충격반응함수·경로별 금전 영향이 아니다.

## 판단 변경과 감사

- 종합점수 대신 기준별 수치와 충족/미충족 이유를 보인다. 계수 크기(효과), q(검정), RMSE(예측), 부호 안정성을 합산하지 않는다.
- 브라우저에서는 네 판정 임계값만 변경할 수 있다. 변경 이유·시각·이전/이후 값·실행 ID를 기록한다. 모형을 재학습했다고 표현하지 않는다.
- 초안은 실행 ID별 localStorage에만 보관한다. 다른 브라우저·다른 실행 결과로 자동 전파하지 않으며 운영 기준은 바뀌지 않는다. 내보내기는 다운로드다.
- 학습 기간·시차·입력·기준 변경 후 재계산은 `--policy`, `--as-of`로 수행한다. 채택하려면 원본 `policy.json`을 검토해 갱신하고 이유·버전을 올린 뒤 새 배포를 실행한다.
- 검증 보고서는 원본 기준·수정 초안·개별 결과·모형 버전·입력 SHA-256·환경 버전·변경 이력을 포함한다. `data/causal/runs/<run-id>.json`은 재현용 로컬 스냅샷이다. 같은 ID에서 내용이 다르면 빌드가 실패한다.
- 가설의 수정은 `relations.json`의 sign/mechanism/bridges를 고치고 다시 빌드한다. 기존 설명 원문은 거시 상세에서 읽으며 해당 HTML 내용 해시도 포함한다.
- 후보가 바뀌어도 기존 과거 스냅샷은 남긴다. 현재 브라우저 UI는 다른 실행 사이의 자동 비교까지 제공하지 않는다.

## 재실행

```powershell
python -m venv .venv-network
.venv-network/Scripts/python.exe -m pip install -r requirements-network.txt
.venv-network/Scripts/python.exe tools/test_network_analysis.py
.venv-network/Scripts/python.exe tools/build_causal_network.py
.venv-network/Scripts/python.exe tools/build_causal_network.py --policy path/to/causal-policy-draft.json --as-of 2026-09-04
python tools/deploy_dashboard.py
```

기본 운영 배포는 공식 `data/causal/policy.json`으로 다시 계산한다. `--as-of`는 최신 수정본을 날짜로 자르는 기능이며 시점별 vintage 복원이 아니다. 별도 기준 실험은 로컬 HTML에 반영되지만 공식 기준을 채택하지 않고 운영 배포하면 공식 기준으로 돌아간다. 과거 원본 CSV를 교체하면 해시만으로 그 원본을 복구할 수 없으므로 데이터 저장소에 원본 버전도 보관해야 한다.

## 향후 적용 규칙: 장기 전달과 신경망

월/분기 주기·공개 시차·계절조정·실질/명목 구분·빈티지 테이블을 구축한 뒤 별도 모형으로 확장한다. 가격은 로그차분, 금리는 %p 차분을 검토하며 수준의 공적분이 확인되면 VECM을 고려한다. 이 장기 모형은 이번 주간 가격 검사와 혼합하지 않는다.

다변량 VAR/국소투영, PCMCI, 변화점·국면별 모형은 미구현이다. PCMCI도 관측되지 않은 공통 원인·정상성 등의 가정이 필요하다. LSTM/TCN/GNN은 충분한 표본이 생기면 단순 모형 대비 out-of-sample 성능으로 채택하며, attention/가중치를 인과 강도로 보이지 않는다. 그래프의 순환은 시간 지연이 있는 관계로 저장하고 미래의 영향 전파 엔진은 같은 충격의 중복 계산을 방지해야 한다. 현재는 숫자 충격을 가설망 전체에 곱해 전파하지 않는다.
