    방법과 한계

    무엇을 계산했나요?

    무엇을 뜻하지 않나요?

    선행 예측력은 구조적 인과의 증명이 아닙니다. 시장 시차를 통제해도 금리·업황·공시 등 누락 변수가 남습니다. 원본은 현재 수정본이며 당시 공개 시점·수정 이력을 복원하지 않았으므로 투자 백테스트 수익률로 해석하지 않습니다.

    거시 변수 대부분은 아직 대응 시계열이 없습니다. 해당 연결은 ‘미검증 가설’로 남습니다. 단기 주간 모형은 수개월~수년의 전기요금·부동산 전달 경로를 검증하지 않습니다.

    확장 방향: 2D·3D와 분석 알고리즘

    현재 지도는 Cytoscape.js의 2D Canvas 그래프입니다. CSS는 외곽 화면을 담당합니다. 군집 개요 → 선택 변수 주변 1·2단계 → 전체 상세 순서로 탐색해 복잡도를 줄입니다. 점의 거리나 중앙 위치는 영향력 점수가 아닙니다.

    3D는 공간적 가림·깊이 판단·텍스트 읽기 비용이 커 기본 화면으로 채택하지 않았습니다. 데이터 규모와 실제 렌더링 시간을 측정한 뒤 WebGL 2D, 서버 부분 그래프 조회, 필요하면 보조 3D 화면을 추가합니다. 렌더링 엔진과 분석 모델은 독립적으로 교체할 수 있습니다.

    월·분기 계열과 발표 시점이 확보되면 다변량 VAR·국면별 추정, 조건부 독립 기반 PCMCI를 검토합니다. 신경망·GNN은 충분한 표본과 독립 검증이 마련된 뒤 비교할 예측 모델이며 가중치가 곧 인과 강도는 아닙니다.
